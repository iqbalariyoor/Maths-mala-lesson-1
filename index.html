പൂർണ്ണവർഗങ്ങൾ (Perfect Squares)

⭐ എന്താണ് പൂർണ്ണവർഗങ്ങൾ?

1, 4, 9, 16, 25, ... എന്നീ സംഖ്യാക്രമം ഓർമ്മയുണ്ടോ? അഞ്ചാം ക്ലാസിൽ സമചതുര സംഖ്യകൾ എന്ന് പഠിച്ചവയാണിത്!

$1 = 1 \times 1 = 1^2$
$4 = 2 \times 2 = 2^2$
$9 = 3 \times 3 = 3^2$
$16 = 4 \times 4 = 4^2$

1, 2, 3, ... എന്നീ എണ്ണൽസംഖ്യകളുടെ വർഗങ്ങളായ 1, 4, 9, 16, 25 ... എന്നിവയ്ക്കാണ് പൂർണ്ണവർഗങ്ങൾ (Perfect squares) എന്ന് പറയുന്നത്.

📐 രണ്ടക്ക സംഖ്യകളുടെ വർഗ്ഗം കാണാൻ എളുപ്പവഴി

ഉദാഹരണത്തിന് $13^2$ കാണാം:

$13^2 = (10 + 3)^2$
$= 10^2 + (10 \times 3 \times 2) + 3^2$
$= 100 + 60 + 9 = 169$

പൊതുവായ സമവാക്യം: $(a + b)^2 = a^2 + 2ab + b^2$. ഇത് കളം വരച്ച് (Grid method) വളരെ എളുപ്പത്തിൽ കണ്ടെത്താം.

കളം വരച്ച് ഗുണിക്കൽ (Grid Method)

രണ്ടക്ക സംഖ്യകളുടെ വർഗ്ഗം കളം ഉപയോഗിച്ച് കാണുന്ന രീതി.

രണ്ടക്ക സംഖ്യാ വർഗ കാൽക്കുലേറ്റർ
